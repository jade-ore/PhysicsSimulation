\## What we have so far:

We have a graphics library that abstracts all of the confusing VAO, Shader, and VBO stuff into simple shape classes with Quads, Triangles, and Circles. 



\## Goals for this project

Turn this library into a physics simulator which can simulate springs, gravity, collisions, and maybe fluids
